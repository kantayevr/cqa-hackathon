# Conversation Quality Analytics

Прототип команды **Кванты** для CQA Hackathon от Freedom Broker. Система оценивает работу оператора по транскриптам чатов и звонков на русском, казахском и английском языках.

## Возможности

- Автоматическая оценка по настраиваемому чек-листу с общим баллом, итогами по разделам и обоснованиями по критериям.
- Переход от обоснования к нужной реплике и открытие записи звонка.
- Сохранение рабочего чек-листа и переоценка выбранного диалога.
- Апелляция по критерию, решение проверяющего и пересчёт итогового балла с историей изменений.

## Запуск на Windows

Для запуска нужны Node.js и Ollama. Проект использует стандартные модули Node.js. Команды ниже выполняются в PowerShell из корня проекта.

1. Запустите Ollama и скачайте модель `qwen3:4b`.

   ```powershell
   ollama pull qwen3:4b
   ```

   Если PowerShell не находит `ollama`, используйте путь стандартной установки Windows.

   ```powershell
   & "$env:LOCALAPPDATA\Programs\Ollama\ollama.exe" pull qwen3:4b
   ```

2. Скачайте DEV-набор через API организаторов. Ссылка находится на кнопке «Открыть GET для DEV» на странице 3 основного гайда. Вставьте ссылку после приглашения PowerShell.

   ```powershell
   New-Item -ItemType Directory -Path .\data -Force | Out-Null
   $devUrl = Read-Host 'Вставьте ссылку GET для DEV'
   curl.exe --fail --silent --show-error --output .\data\dev.json "$devUrl"
   if ($LASTEXITCODE -ne 0) { throw 'Не удалось загрузить DEV-набор' }
   ```

3. Запустите сервер и откройте [веб-интерфейс](http://127.0.0.1:3000). При запуске сервер загружает транскрипты из `data/dev.json` и готовые результаты из `results/dev/results.json`.

   ```powershell
   node .\server.js
   ```

## Пакетная оценка

Локальная модель по умолчанию — **Qwen3 4B (`qwen3:4b`)**. Итоговый балл рассчитывается в `score.js` с учётом весов и `N/A`.

| Набор | Входной файл | Выходной файл | Записей |
| --- | --- | --- | --- |
| DEV | `data/dev.json` | `results/dev/results.json` | 65 |
| PROD | `data/prod.json` | `results/prod/results.json` | 10 |

Для повторного прогона DEV используйте эту команду.

```powershell
node .\evaluate-batch.js dev "Кванты"
```

Когда организаторы откроют контрольный набор, сохраните ответ их API в `data/prod.json` и запустите оценку.

```powershell
node .\evaluate-batch.js prod "Кванты"
```

После остановки прогона та же команда продолжает обработку с сохранённого прогресса при совпадении входных данных, команды, модели и правил оценки. Итоговые файлы записываются в UTF-8 по схеме `1.0`.

## Данные

В `results/` хранятся файлы для сдачи. В локальной папке `data/` хранятся транскрипты, ссылки на записи, рабочий чек-лист, промежуточные результаты и решения по апелляциям. Папка `data/` исключена из Git.
